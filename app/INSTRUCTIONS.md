# 🐰 Клиентское приложение «shit кофе» (REA)

Клиентское PWA приложение для гостей кофейни: выбор напитков, настройка добавок (сиропы, молоко, топинги), корзина, промокоды, штампы лояльности и онлайн-заказ.

## 🔗 Подключение к локальному бэкенду и админке (`REA-ADMIN`)

Админка и бэкенд работают на **`http://localhost:3000`** (проект `REA-ADMIN`).

Чтобы клиент отправлял заказы в реальную базу данных админки и они сразу отображались на экране бариста (KDS):

### 1. Создайте файл `.env.local` в папке `app/`:
```env
VITE_API_URL=http://localhost:3000/api/v1
```

### 2. Запустите клиент:
```bash
npm run dev
```
Клиент откроется на **`http://localhost:5173`**.

---

## 🔐 Разграничение доступов (RBAC) в админке

В панели управления `REA-ADMIN` реализованы 3 роли:
1. **Владелец (`owner`)**: Полный доступ ко всем модулям, P&L, выручке, налогам и зарплатам.
2. **Управляющий (`manager`)**: Управление заведением, стоп-листом, меню и заказами.
3. **Бариста (`barista`)**: Доступ **только** к KDS табло (`/kds`) и очереди выдачи (`/orders`). Финансы, выручка и телефоны клиентов скрыты.
   - Вход по PIN: **`1234`** (Алексей) или **`4321`** (Мария).

## 🧪 Как проверить всю связку локально:
1. В одной вкладке терминала запустите админку и API:
   ```bash
   cd REA-ADMIN && npm run dev
   ```
   (Админка и бэкенд на `http://localhost:3000`)
2. В другой вкладке запустите клиент:
   ```bash
   cd REA/app && npm run dev
   ```
   (Клиент на `http://localhost:5173`)
3. В браузере:
   - Откройте KDS табло бариста: `http://localhost:3000/kds`
   - В соседней вкладке откройте клиент: `http://localhost:5173`
   - Сделайте заказ в клиенте — **он мгновенно со звуком появится на табло бариста `http://localhost:3000/kds`** и в журнале заказов!
   - Бариста нажимает «Готовим» -> «Готово» — статус заказа меняется в реальной базе данных!
