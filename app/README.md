# 🐰 «shit кофе» — Клиентское приложение (PWA)

Современное клиентское PWA-приложение для гостей кофейни «shit кофе»: меню напитков и выпечки, интерактивная карточка товара с выбором добавок (сиропы, альтернативное молоко, посыпки), корзина, система лояльности «6-й кофе в подарок», промокоды и онлайн-заказ с отслеживанием статуса приготовления в реальном времени.

---

## 🚀 Быстрый запуск

```bash
# 1. Установка зависимостей
npm install

# 2. Локальный запуск (по умолчанию http://localhost:5173)
npm run dev

# 3. Запуск тестов (97 тестов, 100% прохождение)
npm test

# 4. Продакшн сборка (Vite + TypeScript + Service Worker)
npm run build
```

## 🔗 Подключение к бэкенду и админке (`REA-ADMIN`)

Клиент поддерживает работу как в автономном режиме (offline / mock data), так и в связке с реальным бэкендом на Next.js (`REA-ADMIN`).

Для подключения к серверу создайте файл `app/.env.local`:
```env
VITE_API_URL=http://localhost:3000/api/v1
```

При подключении к бэкенду:
* Заказ уходит в SQLite базу данных админки.
* Мгновенно со звуковым уведомлением отображается на табло бариста (`/kds`).
* Изменение статуса бариста («Принят» → «Готовим» → «Готов» → «Выдан») в реальном времени передаётся клиенту через **Server-Sent Events (SSE)** и умный опрос.

## 📱 Ключевой функционал приложения

* **Каталог и Меню (`/`):**
  * Сетка товаров с быстрой кнопкой добавления в корзину `+`.
  * Sticky-навигация по категориям с подсветкой активного раздела при скролле.
  * Hero-баннер фирменных напитков.
  * Стоп-листы (автоматически прилетают из базы данных админки).
* **Карточка товара (`#/product/:id`):**
  * Парящая анимированная чашка с адаптивным масштабом под выбранный размер (S / M / L).
  * Динамический пересчёт нутриентов (КБЖУ: калории, белки, жиры, углеводы).
  * Выбор альтернативного молока, сиропов, посыпок и доп. шотов эспрессо.
  * Выпадающая шторка выбора добавок с анимацией прямо над чашкой.
  * Быстрое добавление в корзину с отображением итоговой цены.
* **Корзина и Оформление (`#/cart`):**
  * Единый плавный скролл всех позиций без двойных скроллбаров на десктопе.
  * Постоянно закрепленная внизу широкая кнопка оплаты с ценой и индикатором загрузки.
  * Выбор времени выдачи («Как можно скорее» или ко времени: +15, +30, +45 мин).
  * Выбор способа оплаты (картой онлайн или при получении).
  * Допродажа десертов («Добавить к заказу») в один клик.
  * Поле ввода промокодов (`ЗЕРНО10`, `ОСЕНЬ`).
* **Экран Заказа (`#/order/:id`):**
  * Отслеживание приготовления в реальном времени: этапы «в очереди», «изучаем рецепт», «готовим ингредиенты», «взбиваем и смешиваем», «последние штрихи», «аккуратно упаковываем».
  * Живой расчет оставшегося времени готовности.
  * Возможность отмены заказа до начала приготовления.
  * Оценка качества («Всё хорошо?» / «Плохо») после выдачи.
* **Профиль и Программа Лояльности (`#/profile`, `#/login`):**
  * Быстрая авторизация по номеру телефона с нормализацией к формату `+7 (XXX) XXX-XX-XX`.
  * Уровни лояльности со скидками до 7%.
  * Карточка штампов: 6-й кофе в подарок 🎁.
  * История прошлых заказов с кнопкой «Повторить».
