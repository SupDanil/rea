# Зерно — меню кофейни (PWA)

MVP: меню и карточка товара. Устройство функций взято из анализа Drinkit
(см. `../docs/drinkit-analysis.md`); бренд, тексты, позиции и иллюстрации свои.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/ с service worker и манифестом
npm run preview  # проверить собранную PWA
```

## Что есть

- Меню: hero активной категории, sticky-табы категорий и подкатегорий с синхронизацией скролла, сетка 2 колонки, стоп-лист.
- Карточка товара (`#/product/<id>`): КБЖУ с пересчётом, «что внутри», связанный товар (горячий/холодный),
  группы добавок (одиночный выбор или до N), размеры M/L, итоговая цена, добавление в корзину (счётчик).
- Корзина (`#/cart`): плашка в меню, счётчики, удаление с «Вернуть», допродажа еды, имя для бариста,
  время выдачи (сразу / 15 / 30 / 45 мин), промокоды `ЗЕРНО10`/`ZERNO10` и `ОСЕНЬ`, демо-оплата.
- Заказ (`#/order/<id>`): номер, статусы «Принят → Готовим → Готово» с подэтапами, отмена с подтверждением,
  оценка «Всё хорошо?». Демо-тайминг: заказ «сразу» готов примерно через 45 секунд.
- Профиль (`#/profile`, вход `#/login`): вход по номеру с демо-кодом `1234`, уровни «Зерно → Росток → Обжарка → Эспрессо»
  (0/3/5/7% за 0/3/8/15 заказов), штампы (заказ от 300 ₽, 6 штампов = напиток до 350 ₽ в подарок),
  приветственный подарок, история заказов с «Повторить», настройки (имя, e-mail, уведомления, тема), выход.
- Корзина, заказы, профиль, имя и тема хранятся в localStorage и синхронизируются между вкладками.
- Тёмная тема: по системе или кнопкой в шапке.
- PWA: манифест, иконки, офлайн-кеш (vite-plugin-pwa).

## Где что

- `src/data/menu.ts` — данные и типы (категория → позиция → размеры → группы добавок).
- `src/components/MenuScreen.tsx`, `ProductScreen.tsx` — экраны.
- `src/components/ItemArt.tsx` — SVG-иллюстрации товаров и добавок.
- `src/store.ts` — корзина, заказы, статусы, сохранение; `src/theme.ts` — тема.
- `src/loyalty.ts` — профиль, уровни, штампы, подарки; `LoginScreen.tsx`, `ProfileScreen.tsx` — вход и профиль.
- `src/components/CartScreen.tsx`, `OrderScreen.tsx`, `MenuDock.tsx` — корзина, заказ, нижняя плашка.

Оплаты и бэкенда нет: заказ «создаётся» локально, деньги не списываются.
