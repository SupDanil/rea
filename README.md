# Зерно — PWA кофейни

Мобильное веб-приложение кофейни: меню, карточка товара с добавками, корзина, заказ со статусами,
профиль с уровнями и штампами, тёмная тема. Работает офлайн и ставится на домашний экран.

- `app/` — приложение (React + TypeScript + Vite + vite-plugin-pwa), подробности в [app/README.md](app/README.md)
- `docs/` — заметки об устройстве функций, на которые ориентировались

## Локальный запуск

```bash
cd app
npm install
npm run dev
```

## Деплой на GitHub Pages

Workflow [.github/workflows/deploy.yml](.github/workflows/deploy.yml) собирает `app/` и публикует его
при каждом пуше в `main`. Адрес: `https://<пользователь>.github.io/<репозиторий>/`.

Один раз в настройках репозитория: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Бэкенд — `REA-ADMIN` (Next.js): меню, SMS-коды, заказы, профиль и промокоды приходят из его API.

## 🧪 Тестирование и надёжность

Перед любым коммитом и пушем запускается полный набор автоматических тестов (Vitest + React Testing Library):
```bash
cd app
npm test && npm run build
```
В проекте реализовано **196 тестов в 26 тест-сьютах** (100% Passed), покрывающих:
- Температурные режимы напитков (Hot / Cold / Both): переключатели в карточке меню и на экране продукта, бейджи «🧊 Лёд» / «☕ Горячий», динамическая смена фото с fallback.
- Доменную модель корзины: разделение напитков по температуре, расчёт скидок, промокоды, списание бонусов.
- Логику заказов, смену статусов («Создан» → «Готовим» → «Готов» → «Выдан»).
- Умную выдачу по модели Luckin Coffee: 2D QR-код готового заказа (`ORD:<id>`), кнопка ручного подтверждения «✓ Заказ забрал», приятный экран завершения с оценкой бариста.
- Выбор кофейни сети (`ShopPickerSheet`): сохранение выбранной точки в localStorage, переключение филиала из шапки меню и корзины, расчёт времени готовности.
- Презентационный слой: карточка готового заказа с изумрудным градиентом, подсветкой, адаптивные модальные шторки (стрелка `<` на смартфонах и стильный крестик `✕` на десктопе).
- HTTP-клиент, TanStack Query хуки, хранение состояния в localStorage и профиль пользователя.
